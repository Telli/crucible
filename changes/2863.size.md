- scene:agent-scene: the scene builder checks a displace source material before building and folds the material height into the geometry cache key, so editing a graph rebuilds the mesh that follows it; that is the only core part (mesh-displace-keys.js), sampling stays in the lazy mesh module
- scene:agent-scene+lazy: the sampler (graph height and image) is new lazy code, loaded only by scenes with a mesh geometry
- goal:agent-scene: an agent-facing capability (one height shapes both the silhouette and the normal map); the core share is about 1.2 KB gzip, with no new runtime dependency
