- Studio is now one full-screen viewport with floating controls and icons, its handles follow the object's own axes, the selected object gets an outline, undo takes back one whole drag and leaves the camera alone, and the colours and fonts come from the brand kit. Studio is no longer a page of the public site: it stays an addon that an app embeds, with a development page under `bench/studio`. When an agent edits the scene, a pointer with the agent's name, in a colour of its own, travels to each object it changed. The viewport gains working aids: a ground grid in metres with the X and Z axes, a view widget that snaps to the main views, and a readout of the camera and the size of the selection. Move handles end in arrows, and Studio opens on a plain blockout scene of three grey primitives. Turning a ring shows where the turn began and a faint wedge over the angle turned so far (#2177).
