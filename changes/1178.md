- A glTF file with lights no longer gets the renderer's studio key and fill lights on top of its own: `asset.lights` sets `fillIntensity` to 0, and `keyIntensity` to 0 when no light is directional. On a test scene (grey and coloured cards, one sky, one point light) mean luma was 224 with saturation 18.5, and is now 204 with saturation 33.2, within 1 level of three.js drawn with the same ACES curve (#1178).
