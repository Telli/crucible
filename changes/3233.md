`npm run render -- --scene file --kind stills --frames 0-89 --fps 30` renders a scene file to a numbered PNG sequence (`frame-0000.png` to `frame-0089.png`), each frame at exactly frame / fps, up to 3600 frames per run. A scene file's `frame.effects.motionBlur` (`shutter` and `objects`) now smears camera motion and the GLB clip's moving parts on this path, and two runs of the same range give identical PNG bytes (#3233).
