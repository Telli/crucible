# Bake light

`crucible/addons/light-bake` writes the light that bounces between surfaces into one lightmap texture per part. Recipes reach it through the `bake` section, so an agent can bake without code.

- Presets, bounce counts and limits: [Light bake](/light-bake.md).
- Without a bake, the realtime lights and sky are in [Effects and lighting](#effects-and-lighting).
