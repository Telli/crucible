# Cook path tracer

![A classroom drawn by the Cook path tracer](/previews/hero-classroom.webp)

Cook (`crucible/addons/path-tracer`) draws one still by following light paths on the CPU or GPU. Glaze, the realtime renderer, draws every frame; Cook is for the final picture.

- What it draws, what it does not and its limits: [Cook (path tracer)](/path-tracer.md).
- How it compares with Blender's Cycles on the same scenes: [Cycles parity](https://github.com/codepawl/crucible/blob/main/docs/cycles-parity.md).
